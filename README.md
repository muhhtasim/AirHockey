# 🏒 Neon Air Hockey

A fast-paced **Neon Air Hockey arcade game** built with **HTML5 Canvas, CSS, and JavaScript**.

Play against a CPU opponent, score goals, build streaks, and enjoy a futuristic neon-style arcade experience.

## 🎮 Features

- 🏒 Classic Air Hockey gameplay
- 🤖 CPU opponent with AI
- 🖱️ Mouse controls
- 📱 Touch support
- ⚡ Real-time puck physics
- 💥 Collision detection
- 🔥 Power-hit detection
- 📈 Game statistics
  - Current streak
  - Top speed
  - Power hits
- 🔊 Sound effects
- 🔇 Mute / unmute functionality
- ✨ Particle effects
- 🎉 Confetti effects
- 🐌 Slow-motion effects
- 🏆 First player to reach 7 goals wins
- 🌌 Futuristic neon interface
- 📱 Responsive gameplay

## 🕹️ Controls

| Input | Action |
|---|---|
| 🖱️ Mouse | Move your mallet |
| 👆 Touch | Move your mallet on mobile |
| `S` | Toggle sound |

## 🏆 Game Rules

- Play against the CPU opponent.
- Each goal increases the corresponding player's score.
- The first player to reach **7 goals** wins the match.
- Game statistics are tracked throughout the match.

## 🛠️ Technologies Used

- **HTML5** — Game structure and UI
- **CSS3** — Styling and visual effects
- **JavaScript (ES6+)** — Game logic
- **HTML5 Canvas API** — Game rendering
- **Web Audio API** — Sound effects
